# 支持与限制

声明范围：Unity 2022.3.62f3，旧输入系统，.NET Standard 2.1，macOS Development Mono。测试、构建、运行证据由发行验收报告给出；没有证据的环境不声明已支持。

IL2CPP平台运行模块缺失，WebGL、Windows、Android、iOS、微信/抖音/快手SDK和设备未验证。框架提供技术机制，不含这些厂商SDK或身份/广告/购买支持。不是完整混合变现游戏。

当前性能完整负载、内存增长归因、目标冷缓存及批准预算按用户要求暂缓；分配计数器阳性控制失败时分配未知，不宣称零GC。桌面可运行不等于性能达标。

依赖：UniTask2.5.11、R3 Unity/Core1.3.0、YooAsset2.3.17、TMP3.0.7、uGUI1.0.0；Git提交见套件dependencies.json。核心官方DLL与原许可完整保留。无Luban/MessagePack；网络Protobuf为另一个可选工具，未加入此发行套件。

仅声明本次演练的源码与存档兼容，不保证所有二进制消费者。API元数据差异需要评审，变更记录必须与实际版本对应。源码修复回到唯一开发工程，发行仓库由白名单组装，不能两处独立修改。
