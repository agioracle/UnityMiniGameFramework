# Changelog

## 0.1.3 — 2026-10-22

兼容修复：LegacyPointerInput.IsConsumedByUi 在访问EventSystem前拒绝非有限位置，与Feed校验一致。公开签名不变，新增边界回归；发行安装和0.1.2→0.1.3→0.1.2回滚使用冻结消费者/用户样例与存档验证。

## 0.1.2 — 2026-10-22

修复发行验证消费者PlayMode发现配置与目标Editor锁检查。0.1.1包内基础与样例测试通过，但消费者样例测试未发现，因此不把该批结果当升级基线。

## 0.1.1 — 2026-10-22

修复首次干净安装发现的缺少Audio等Unity内置模块声明；安装器完整链接输入保护、失败备份保留和Unity生成meta兼容。0.1.0首轮干净工程编译失败，保留产物与日志，不作为可用发行推荐。

## 0.1.0 — 2026-10-22

首次版本化独立预览套件：底层服务、两个自有 UPM 包、固定 Git 外部依赖、可导入 Basic、独立测试夹具、安装/校验工具和随包许可/文档。与已有开发版本号一致，但这是第一次独立套件验收，不冒充历史发行。

## 版本政策

0.x.y 为预览版本。兼容修复升 patch，预览期破坏性接口变化升 minor，并记录迁移；正式 1.x 后按 SemVer。第三方依赖版本、消费者 schema、内容版本和框架版本分别管理。发行目录不可原地修改。API 删除/更改、资源 GUID 变化、依赖升级都必须经过消费者回归；元数据对比不能替代行为测试。
